**Тема:** Классы и объекты  
**Выполнил:** Мацкевич Кирилл  
**Группа:** 550501  

---

## Цель работы
Создание консольного приложения «Служба доставки» для управления заказами и транспортом с использованием ключевых принципов ООП, безопасного ввода данных и контроля версий через Git.

---

## Структура проекта
* `Order.h` / `Order.cpp` — класс сущности «Заказ» (валидация веса, статусы).
* `Vehicle.h` / `Vehicle.cpp` — класс сущности «Транспорт» (ограничения типов и грузоподъёмности).
* `DeliveryService.h` / `DeliveryService.cpp` — класс-менеджер для бизнес-логики и управления списком объектов.

---

## Основной функционал
1. **Ручное добавление данных:** ввод новых курьеров и заказов через текстовое меню.
2. **Просмотр списков:** вывод текущей информации о транспорте и заказах.
3. **Автоматическое назначение:** поиск наименьшего подходящего по грузоподъёмности свободного транспорта под вес заказа.
4. **Завершение доставки:** освобождение транспорта и удаление доставленного заказа.
5. **Защита от ошибок ввода:** устойчивость к вводу некорректных символов (букв, пробелов и спецсимволов).

# Лабораторная работа №2

**Тема:** Дружественные функции, перегрузка функций и операторов  
**Выполнил:** Мацкевич Кирилл  
**Группа:** 550501  

---

## Цель работы
Расширение программной системы «Служба доставки» механизмами перегрузки операторов C++ (сравнения, ввода-вывода, управления коллекциями) и использования дружественных функций (`friend`) для работы с закрытыми данными классов.

---

## Структура проекта
* `Order.h` / `Order.cpp` — класс «Заказ» с перегруженными операторами сравнения (`==`, `!=` по ID; `<`, `>`, `<=`, `>=` по весу) и потокового ввода-вывода (`<<`, `>>`).
* `Vehicle.h` / `Vehicle.cpp` — класс «Транспорт» с перегруженными операторами сравнения (`==`, `!=` по ID; `<`, `>`, `<=`, `>=` по грузоподъёмности) и потокового ввода-вывода (`<<`, `>>`).
* `DeliveryService.h` / `DeliveryService.cpp` — класс-менеджер с перегруженными операторами модификации коллекций `+=` (добавление) и `-=` (удаление).
* `ConsoleUI.h` / `ConsoleUI.cpp` — интерактивное консольное меню, обработчики команд сравнения и вывода характеристик объектов.
* `main.cpp` — чистая точка входа в приложение.

---

## Основной функционал
1. **Сравнение объектов:** операторы равенства по уникальному идентификатору (`==`, `!=`) и отношения по числовым характеристикам (`<`, `>`, `<=`, `>=`).
2. **Потоковый ввод-вывод:** считывание объектов из потока ввода через `std::cin >>` (с помощью `friend`-функции) и вывод в поток `std::cout <<`.
3. **Управление коллекциями через операторы:** удобное добавление транспорта и заказов в систему через `+=` и удаление заказов через `-=`.
4. **Защита и бизнес-ограничения:** блокировка изменения характеристик и удаления объектов, находящихся в процессе доставки, а также проверка уникальности ID.

# Лабораторная работа №3

**Тема:** Наследование классов  
**Выполнил:** Мацкевич Кирилл  
**Группа:** 550501  

---

## Цель работы
Расширение программной системы «Служба доставки» иерархией классов: выделение базовой сущности «Транспорт» и трёх специализированных сущностей («Мотоцикл», «Машина», «Грузовик») с общими характеристиками и специфическими свойствами, использование наследования для исключения дублирования кода.

---

## Структура проекта
* `Vehicle.h` / `Vehicle.cpp` — базовый класс «Транспорт» с общими характеристиками (ID, грузоподъёмность, курьер, статус, текущий заказ), защищённым конструктором и единой проверкой грузоподъёмности `validate_capacity()`.
* `Motorcycle.h` / `Motorcycle.cpp` — производный класс «Мотоцикл» (грузоподъёмность до 50 кг, специфическое поле — наличие термокороба).
* `Car.h` / `Car.cpp` — производный класс «Машина» (грузоподъёмность до 1500 кг, специфическое поле — объём багажника от 100 до 2000 л).
* `Truck.h` / `Truck.cpp` — производный класс «Грузовик» (грузоподъёмность до 10000 кг, специфическое поле — наличие гидроборта).
* `DeliveryService.h` / `DeliveryService.cpp` — класс-менеджер, хранящий транспорт разных типов в общей коллекции.
* `ConsoleUI.h` / `ConsoleUI.cpp` — консольное меню: добавление транспорта с выбором типа, управление транспортом.
* `Order.h` / `Order.cpp`, `InputUtils.h` / `InputUtils.cpp`, `main.cpp` — сущность «Заказ», безопасный ввод данных, точка входа.

---

## Основной функционал
1. **Иерархия классов:** публичное наследование `Motorcycle`, `Car` и `Truck` от `Vehicle`; общие данные и методы описаны только в базовом классе, производные добавляют лишь специфические свойства.
2. **Конструкторы и доступ к полям:** конструкторы по умолчанию и с параметрами, передача общих параметров конструктору базового класса через список инициализации, методы доступа к специфическим полям.
3. **Переопределение методов:** `get_type()`, `get_max_capacity()` и `get_full_info()` переопределены в производных классах; `get_full_info()` дополняет информацию базового класса специфическими полями.
4. **Повторное использование кода:** операторы сравнения и ввода-вывода реализованы один раз в базовом классе и работают для всех типов транспорта; оператор `>>` производных классов использует оператор базового класса и запрашивает только специфические поля.
5. **Ограничения предметной области:** грузоподъёмность не может превышать максимум для типа транспорта, объём багажника ограничен диапазоном 100–2000 л, запрещено изменять ID, грузоподъёмность и статус транспорта во время выполнения заказа.

# Лабораторная работа №4

**Тема:** Полиморфизм, виртуальные функции, абстрактные классы  
**Выполнил:** Мацкевич Кирилл  
**Группа:** 550501  

---

## Цель работы
Расширение иерархии классов транспорта механизмами динамического полиморфизма: превращение базового класса в абстрактный, реализация виртуальных методов в производных классах и единообразная работа с разнотипными объектами через указатель на базовый класс.

---

## Структура проекта
* `Vehicle.h` / `Vehicle.cpp` — абстрактный базовый класс с чисто виртуальными методами (`get_type()`, `get_max_capacity()`, `perform_specific_action()`, `get_specific_action_name()`, `calculate_delivery_cost()`), виртуальным `get_full_info()`, виртуальным деструктором и методом `can_carry()` для проверки возможности перевозки груза.
* `Motorcycle.h` / `Motorcycle.cpp`, `Car.h` / `Car.cpp`, `Truck.h` / `Truck.cpp` — производные классы, переопределяющие все виртуальные методы (`override`) со своими тарифами и специфическими действиями.
* `DeliveryService.h` / `DeliveryService.cpp` — класс-менеджер с коллекцией `std::vector<std::unique_ptr<Vehicle>>` и полиморфными операциями над всем транспортом.
* `ConsoleUI.h` / `ConsoleUI.cpp` — консольное меню: специфические действия и расчёт стоимости доставки для всего транспорта и для выбранного объекта.
* `Order.h` / `Order.cpp`, `InputUtils.h` / `InputUtils.cpp`, `main.cpp` — сущность «Заказ», безопасный ввод данных, точка входа.

---

## Основной функционал
1. **Абстрактный базовый класс:** `Vehicle` содержит чисто виртуальные методы, поэтому объект базового класса создать нельзя; объекты создаются только для производных типов.
2. **Специфическое полиморфное действие:** `perform_specific_action()` (переключение термокороба, проверка вместительности багажника, переключение гидроборта) и `calculate_delivery_cost()` (расчёт стоимости доставки по тарифу конкретного типа транспорта) — результат зависит от фактического типа объекта.
3. **Коллекция указателей на базовый класс:** объекты `Motorcycle`, `Car` и `Truck` хранятся в одной коллекции `std::unique_ptr<Vehicle>` и обрабатываются единообразно.
4. **Полиморфные вызовы:** вывод информации о всём транспорте (`<<` вызывает виртуальный `get_full_info()`), выполнение специфических действий для всего транспорта, расчёт стоимости доставки груза заданного веса для каждого транспорта, название специфического действия в меню через `get_specific_action_name()`.
5. **Управление временем жизни объектов:** владение объектами через `std::unique_ptr` (автоматическое удаление, в том числе при отклонении дубликата ID, без утечек памяти) и виртуальный деструктор в базовом классе.
6. **Проверка возможности перевозки:** метод `can_carry()` используется при назначении заказа, подборе подходящего транспорта и расчёте стоимости доставки.
